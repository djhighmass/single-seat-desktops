# single-seat-desktops
Turns existing Linux accounts on an Android Linux Terminal (crosvm) Debian VM into switchable, real-hardware wayfire desktops.

The installer is in `install/` (see `install/README.md`). Optional applications, such as a terminal, a browser or Claude Code, each from its supplier's own packages, are a separate layer in `apps/` (see `apps/README.md`).
